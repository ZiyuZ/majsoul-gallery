# 雀魂藏馆：产品与开发路线

更新日期：2026-10-24。

## 产品目标

雀魂藏馆定位为角色养成工具，围绕账号收藏、好感、契约要求与现有材料组织功能。牌谱分析交由已有工具处理。主应用位于项目顶层，面向用户发布一个桌面程序。素材查看器作为内部研究、检查和诊断工具。

主导航分为概览、收藏和培养。概览展示素材总量、角色预览与分类入口，登录后补充已拥有数量。收藏展示角色、皮肤、装扮及称号；培养展示好感进度、契约状态和材料缺口。星标对应雀魂中的角色收藏，由账号快照提供。

后续保留公开分享的目标：由用户选择展示范围，生成可交给他人访问的收藏展示。分享成果仅包含选中的展示资料。

## 代码组织

主应用使用 Rust 和 GPUI Kit。默认构建提供静态预览；`spine` feature 启用时使用 wgpu 渲染骨骼动画。本地解析集中在 `crates/majsoul-assets`，主应用和内部素材查看器共同依赖它。

- `src/ui` 负责收藏、培养、详情和模态表单；`shell.rs` 管理标题栏与侧栏，`cards.rs` 统一收藏卡片、图片适配与拥有状态，`filters.rs` 统一控制区框架与角色筛选。
- `src/text.rs` 保存应用名称、导航、分类和常用操作等共用文案；具体功能的说明保留在对应模块。
- `src/discovery.rs` 负责 Steam 安装与库目录发现。
- `src/importer.rs` 负责本地导入任务；`src/task_process.rs` 负责导入和皮肤导出共用的进程、进度与取消。
- `src/storage.rs` 负责导入临时文件清理。
- `src/files.rs` 为配置、账号记录和导出提供共用的临时写入与文件替换。
- `src/skin_export.rs` 负责 PNG、无损／有损 WebP 编码，`src/ui/skin_export.rs` 提供导出表单。
- `src/model.rs` 负责标准素材包的读取、素材模型与装扮分类别名归一化；界面和报表共用分类规则与名称。
- `src/account.rs` 负责账号快照、当前账号会话和材料判断；`src/account/api.rs` 负责 API 结果映射与按账号保存，`src/account/network.rs` 维护后台连接。
- `crates/majsoul-api` 独立实现国际服线路发现、认证、只读查询、协议编码与请求节流。
- `src/report.rs` 负责 HTML 报表，`src/report/image_report.rs` 负责紧凑 PNG 图表，GUI 与 `src/cli.rs` 共用导出逻辑。
- `src/settings.rs` 负责素材来源与界面偏好的保存。
- `crates/majsoul-assets/src/core` 负责资源清单、Unity 对象、配置与语言关联、索引缓存及素材包生成。

素材包协议继续使用 [schema v2](asset-export-format.md)。本地安装、已有素材包与后续网络来源最终提供同一套角色、皮肤和物品身份。

## 导航与窗口布局

标题栏高 48 像素，左侧显示应用图标与名称，右侧为搜索框和窗口按钮。空白区域支持拖动窗口，搜索框独立处理点击和文本选择。首次导入时保留同一标题栏，完成素材准备后显示搜索。

侧栏顶部为概览、收藏、培养导航，底部为账号区域及导出、设置、主题切换和侧栏收起按钮。收起后使用一列图标。主内容直接显示各页面的筛选与浏览区域。

界面采用统一的产品用语。开发诊断写入日志；调试账号启用后显示调试标记。

概览采用单屏布局，展示数量、角色预览和装扮分类入口。拥有状态使用数字表示。浏览区滚动条位于右侧留白，闲置后在原位淡出。

## 单个皮肤导出

详情顶部提供导出入口。静态立绘按原图尺寸保存为 PNG 或无损 WebP；启用 `spine` feature 后，动态皮肤使用多层渲染器离屏生成 WebP 动画。两种内容均可选择透明或白色背景，独立于预览区域的缩放和背景设置。

动画可选择当前动作、长边尺寸（512／1024／1536／2048）、帧率（24／30／60 FPS）和时长。一个周期取合成图层中最长的活动动画时长，也可选择 5、10 或 15 秒。固定时间步逐帧渲染并增量送入编码器，导出在独立进程执行，提供进度与取消。编码结束后写入目标文件。

角色筛选中的限定包含联动，联动项进一步筛选联动角色。宝石表示限定，握手表示联动，图标位于卡片文字区域并提供说明。已拥有使用青绿色，已契约使用暖金色，未拥有使用中性灰。

## 素材与账号的边界

素材库在应用中共享，提供角色、皮肤、物品与契约要求。账号快照按 UID 归属，提供拥有状态、星标、好感、库存与可保存的同步时间；当前账号会话管理选中的快照和连接状态。切换账号整体替换会话数据，登出清空当前会话。

素材更新和账号同步分别执行。重新载入素材保留真实账号快照，新出现且尚未同步的角色使用空状态。调试预览显式生成示例快照，素材更新时可重新生成该快照。

网络层串行查询并生成完整快照，成功后再替换对应账号的数据。账号缓存和同步偏好按区服与 UID 隔离，当前账号选择独立保存。异步结果使用会话代次核对，登出或切换到调试账号后丢弃旧请求的界面结果。

当前提供国际服账号登录、手动同步和周期同步，保持单个活动连接。后续可基于已有分账户目录增加账号选择界面。

### 国际服账号接入与参考资料

第一阶段接入国际服账号密码登录，读取账号信息、角色与皮肤、契约与好感、装扮和材料库存，生成按区服与 UID 保存的账号快照。素材继续来自唯一的本地素材库。网络补充素材作为后续独立任务推进。

协议由 Akagi 的提取脚本从当前国际服 Unity 客户端 `4.0.51` 重新生成。线路发现、握手、认证、只读查询和限流由独立 Rust crate 实现，GUI 使用后台任务接收进度与完整快照。

已确认星标来自 `character_sort`，好感 `exp` 表示当前爱心等级内的进度，初始皮肤与契约皮肤需要结合本地角色配置补齐。无需账号的真实线路握手、心跳与本地模拟服务器测试已纳入验证；真实账号认证、库存及拥有状态仍待账号验收。

连接流程、请求限制、数据归属、协议更新方法及开源项目致谢统一记录在[账号 API](account-api.md)。

## 首次使用与本地导入

1. 优先载入配置中的素材库，默认目录为 `majsoul-gallery-data/materials`。
2. 尚无可用素材包时，在居中表单中显示发现进度。
3. 读取 Steam 注册信息、`libraryfolders.vdf` 和各库的安装清单，核对游戏资源清单与配套 `resources.assets`。
4. 一个有效安装直接导入；多个安装供用户选择；未发现安装时提供目录、exe 和路径输入。
5. 建立或复用索引，恢复名称与关联，生成标准素材包。
6. 验证成功后保存来源并进入概览页面。

首次准备素材时隐藏主内容。已有素材库中的手动导入使用半透明遮罩弹框，点击遮罩或按 Esc 可关闭并取消任务。耗时工作在独立进程完成，界面接收阶段进度并支持取消。导入失败时显示可重试的路径表单。

素材库由应用维护。导入对话框分为本地素材和网络素材，本地支持选择目录、选择程序与自动搜索，选择完成后点击确定导入。默认复用已有内容；启用“重新生成全部素材”会清理并重建当前素材库中的图片与资料。网络素材页签当前禁用，后续接入时要求登录。

## 模态表单组件

`src/ui/form_dialog.rs` 提供共用容器与任务进度内容：

- 顶部标题与说明。
- 有高度边界的表单或进度区域。
- 固定的底部操作区。
- 随窗口和明暗主题调整的布局与颜色。

导入、设置、登录和导出使用该容器。任务状态和业务动作由对应流程管理，容器负责一致的展示。素材来源统一从设置进入，账号区域位于侧栏底部。

## 素材存储与更新

应用旁的 `majsoul-gallery-data` 保存设置、日志、索引、名称关联和导入产物。主界面直接读取生成的素材包。

应用维护唯一素材库 `materials`。默认导入静态图片和结构化资料，`spine` feature 构建额外导入骨架、动画图集和纹理。导入记录包含构建的素材范围，用于判断是否需要补充资源。增量导入直接复用现有文件，按来源失效记录更新变化的图片、图标和动态皮肤，再更新结构化资料。文件写入通过临时文件替换；中断后复用已完成的文件继续导入。全量重新导入会清理并重建当前库。

解码临时文件位于 `import/cache`，同盘支持硬链接时，与最终素材共享磁盘数据。导入完成或报错后清理临时目录；强制结束后的残留在下次启动或导入时清理。索引、名称关联和版本记录持久保存。

后续网络来源仅向这唯一素材库补充缺失资源；来源记录用于更新判断和追踪。

资源更新根据清单及包文件的大小、修改时间判断。启动载入素材库后，在后台检查原安装是否有更新；有变化时开始增量导入。素材来源弹框可手动确认导入，默认复用已有内容。

## 当前实现与后续步骤

当前已实现概览、收藏和培养界面、搜索筛选、角色资料、动态皮肤播放、本地 Steam 发现、增量导入和共用模态表单。默认离线展示全部素材，隐藏拥有状态与账号进度。角色喜好表可按范围导出为内嵌图片的独立 HTML，按紫色礼物分组，左右区分樱花与竹林，金色边框标记限定角色。

登录与同步支持账号、密码、自动同步周期和手动同步。密码在认证后释放，设备标识与账号名保存在设置中；账号快照保存角色、皮肤、装扮、星标、好感、契约、库存及同步时间，供收藏、培养和报表共用。默认启动进入离线浏览。

接下来按以下顺序推进：

1. 使用真实账号验收登录、契约与好感、星标、库存和装扮拥有状态，完善服务器错误处理。
2. 完善账号缓存的离线选用与多账号切换。
3. 实现可选网络素材来源，补充唯一素材库中本地缺少的资源。
4. 实现用户可选择范围的公开收藏展示。

素材来源与账号数据各自管理：本地安装提供图鉴及配置，账号快照提供拥有情况与培养进度。后续记住认证信息时使用系统凭据存储。

解析依据与版本适配方法见[本地资源分析](resources.md)。

动态播放及动画导出由默认关闭的 `spine` feature 控制。官方 runtime 源码保留在本地 `vendor`，由 Git 忽略；默认 Cargo 配置通过可选依赖声明 runtime，`cargo xtask prepare-spine` 下载固定的 runtime 发布包并应用两处内存修复，动态构建通过命令行补丁路径选择该依赖。
